# نشر سَكينة على Railway (خدمة واحدة للتطبيق والسيرفر)

بعد النشر يعمل كل شيء مشترك بين الناس: عداد الصلاة على النبي، وجدار الدعاء، ومنافسة الجمعة، وغرف المسابقات، ولوحة الأدمن.

## الخطوات
1. ادخل railway.app ← **New Project** ← **Deploy from GitHub repo** ← اختر ريبو `sakeena-app-`.
2. افتح الخدمة ← **Settings** ← **Root Directory** اكتب: `sakeena-project`
3. من نفس المشروع اضغط **+ New** ← **Database** ← **Add PostgreSQL**.
4. افتح الخدمة ← **Variables** وأضف:
   - `DATABASE_URL` = `${{Postgres.DATABASE_URL}}`
   - `ADMIN_KEY` = كلمة سر طويلة تختارها أنت (هي باسورد لوحة الأدمن، لا تشاركها مع أحد)
   - (اختياري للإشعارات) `VAPID_PUBLIC_KEY` و `VAPID_PRIVATE_KEY` و `VAPID_SUBJECT`
     ولتوليد المفاتيح: `npx web-push generate-vapid-keys`
5. **Settings ← Networking ← Generate Domain** لتحصل على الرابط.
6. افتح الرابط. هذا هو التطبيق للناس كلها.
7. لوحة الأدمن: **الإعدادات ← لوحة التحكم (للمشرف)** واكتب قيمة `ADMIN_KEY`.

## ملاحظات
- الجداول تُنشأ تلقائيًا عند أول تشغيل، فلا تحتاج أوامر قاعدة بيانات.
- لا تضبط `PORT`، ريلواي يضبطه.
- بعد أي تعديل ترفعه على GitHub يعيد Railway البناء تلقائيًا.
- نسخة الـ Codespace للتجربة فقط وليس فيها سيرفر، فميزات الناس المشتركة لا تعمل فيها.
